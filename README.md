# Flagship Disney Media

Runtime media for the Disney Edition II scroll cinema in
[`Mohamed3042/flagship-portfolio`](https://github.com/Mohamed3042/flagship-portfolio).

- 100 normalized H.264 MP4 clips in `disney2/clips/` (1920×882, Topaz-upscaled from the 1358×624 masters)
- 100 JPEG fallback posters in `disney2/posters/`
- Integrity metadata in `media-manifest.json`

These files are published by GitHub Pages for browser range delivery. This
repository is a delivery artifact; no reuse license is granted.
